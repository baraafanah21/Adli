# خطة العمل: عدلي

كل مرحلة تنتهي بـ `npm run build` و`npm run lint` ناجحين، وفحص الصفحة على عرض جوال، وقائمة قصيرة بما يُفحص على الجوال. صاحب المشروع يراجع ويعمل الكوميت. لا ننتقل للمرحلة التالية قبل إغلاق الحالية.

**تغيير الاتجاه (2026-10-06):** لا نماذج 3D للمنتجات. العنصر ثلاثي الأبعاد الوحيد قنينة الافتتاح الحية (لوحة WebGL واحدة بـ three.js)، مع صورة ثابتة من لقطات Cycles (انظر `design-system/3d-and-motion.md`). للموقع حسابات اختيارية، والطلب كضيف يبقى ممكناً.
