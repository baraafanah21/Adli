# Adli logo files

Traced as vectors from the original logo image (logo.jpg, 1600×1600). A render of adli-logo-square.svg
matches the original to 0.09% of pixels, all on anti-aliased edges. Do not redraw or retype any part of it.

| File | What | Use |
|---|---|---|
| adli-logo.svg | Full logo: seal + "ADLI ▯ عدلي" lockup, forest on transparent (seal interior cream) | Light backgrounds, footer, about |
| adli-logo-mono.svg | Full logo, one colour (`currentColor`) | Dark backgrounds (set `color` to cream or brass) |
| adli-logo-square.svg | Full logo on the cream square, exactly like the original | Social avatars, OG base |
| adli-seal.svg | The seal only (two rings + ع), forest with cream interior | Header mark, badges, loaders |
| adli-seal-mono.svg | Seal only, `currentColor` | On photos and dark surfaces |
| adli-wordmark.svg | The lockup "ADLI ▯ عدلي", forest | Header on wide screens |
| adli-wordmark-mono.svg | Lockup, `currentColor` | Dark header |
| adli-bottle-icon-mono.svg | The perfume bottle from the lockup, `currentColor` | Cart / shop icon, small motif |
| icons/ | favicon.ico (16/32/48), icon-16/32/48/192/512.png, apple-touch-icon.png | App icons, manifest |

Colours: forest #0B300F, cream #F5F5DB (from the original). Mono files take any brand colour via CSS `color`.
Rules: keep clear space of at least the ring width around the seal; seal no smaller than 24px, full logo no smaller
than 120px wide; never stretch, recolour inside the seal, outline, or add effects to the mark itself.
